How to Install

  1. Download the Flourish_Vanilla.zip file above.
  2. Open Minecraft and go to your World Selection screen.
  3. Select your world, click Edit, then click Open World Folder.
  4. Open the datapacks folder and drop the .zip file inside.
  5. Launch the world, or type /reload if you are already in-game!
