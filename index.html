How to Install

  1. Download the Flourish_Vanilla.zip file using the button above.
  2. Install the Fabric Launcher for your Minecraft version.
  3. Open your .minecraft directory on your computer.
  4. Put any required mods into the mods folder.
  5. Put your resource packs into the resourcepacks folder.
  6. Put your shaders into the shaderpacks folder.
  7. When making your new world: Click on the More tab, click Data Packs, and drop the downloaded Flourish_Vanilla.zip file directly into the menu!
