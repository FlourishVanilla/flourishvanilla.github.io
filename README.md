## 🚀 Installation Guide

Setting up your environment ensures the absolute best experience with **Flourish Vanilla**:

1. **Get the Pack:** Download the latest version from our [Website](https://flourishvanilla.github.io) or the GitHub Releases section.
2. **Setup Client Launcher:** Install the **Fabric Launcher** corresponding to your active Minecraft version.
3. **Directory Management:** Access your system's `.minecraft` game folder:
   * 📁 Place any required companion mods directly into the `mods` folder.
   * 📁 Drop your associated resource packs into the `resourcepacks` folder.
   * 📁 Place your desired shaders into the `shaderpacks` folder.
4. **Apply the Datapack:** * Launch Minecraft and begin creating a new world.
   * Navigate to the **More** settings tab, then click on **Data Packs**.
   * Drag and drop the downloaded `Flourish_Vanilla.zip` directly into the game menu to activate it.
